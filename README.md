# Português-semântica-e-funções-de-linguagem-figuras-de-linguagem.-### Guia Definitivo: Funções da Linguagem vs. Semântica

| Matéria | Conceito / Termo | Qual é o foco principal? | Exemplo Prático | Como lembrar na prova? |
| :--- | :--- | :--- | :--- | :--- |
| **Funções da Linguagem** *(A intenção do texto)* | **Conativa (ou Apelativa)** | Convencer ou dar uma ordem ao leitor. | *"**Use** este creme. **Você** merece."* | 📢 **C**onativa = **C**omprar / **C**onvencer |
| | **Metalinguística** | Explicar o próprio código (a linguagem pela linguagem). | Uma música que fala sobre como fazer música. | 📖 **M**etalinguística = **M**esmo código |
| | **Referencial** | Informar um fato de forma neutra e realista. | *"O trânsito parou na Avenida Central devido à chuva."* | 📰 **R**eferencial = **R**ealidade / Notícia |
| | **Fática** | Testar se o canal de comunicação está funcionando. | *"Alô? Oi, tá me ouvindo?"* | 📞 **F**ática = **F**one / Conversa fora |
| **Semântica** *(O significado das palavras)* | **Denotativa** | Sentido literal, real, o do dicionário. | *"O **coração** humano é um órgão muscular."* | 🧬 **D**enotativa = **D**icionário |
| | **Conotativa** | Sentido figurado, simbólico, emocional. | *"Você tem um **coração** de ouro."* | ❤️ **C**onotativa = **C**oração / Criatividade |
